# Security

## How to report a problem

Please report security problems privately. Do not open a public issue.

1. Preferred: use GitHub private vulnerability reporting. Open the **Security** tab of this repository and press **Report a vulnerability**.
2. Secondary: email support@splicerun.com with the subject line `SECURITY`.

Include what you found, where, and how to see it. Do not include real customer data.

## What to expect

- The maintainer is the repository owner. There is no security team.
- Replies are best-effort and no response time is promised.
- No response time is promised. No bug bounty, payment or credit is promised.
- This repository holds documentation and examples. If the problem is in the hosted platform at https://app.splicerun.com, say so; that platform is proprietary and is handled separately.

## Scope

In scope: unsafe guidance in the documentation, and any file in this repository that exposes private content by mistake.

Out of scope: attacks on other people's deployments, denial-of-service testing against the hosted service, and social engineering.

## Please

Give the maintainer a reasonable time before telling anyone else, and do not access data that is not yours.
