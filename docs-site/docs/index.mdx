# SpliceRun documentation

We run your automation app so you can build workflows instead of babysitting
Docker, certificates and night-time restarts. The app today is **n8n**, on Bring your own server, the plan you can order today (Shared and Dedicated are described for reference but are not open for orders). These pages cover how that works, exactly where our responsibility ends and yours
begins, and what to do at 11pm when something has stopped.

</div>
